# Support

## Current verified contact

**`privacy@streampulse.stream`** — privacy and legal inquiries **only**. It is not a routine
product-support mailbox.

## Hosted support form

A hosted StreamPulse support form (Turnstile + durable outbox) is **implementation
complete; activation pending** under RPR-4 and is **not active**.

Do not expect a working in-product support ticket path until activation is
owner-approved and publicly disclosed. Feature flags and vendor credentials stay
off.

## Public repository

[`Aron-Chu/streamclone-pulse`](https://github.com/Aron-Chu/streamclone-pulse) is
**public**. Forks and pull requests are welcome under
[`CONTRIBUTING.md`](CONTRIBUTING.md). Do not paste secrets, DSNs, exploit details,
or production topology into issues or PRs.

Historical private history (pre-clean export) lives in the private archive
`streamclone-pulse-private-archive` and is not a contribution surface.

## What not to use yet

The following are **not** published as active channels:

- `support@…` product-support mailbox
- `security@…` security mailbox (use GitHub Private Vulnerability Reporting —
  see [`SECURITY.md`](SECURITY.md))

## How to ask for help today

1. Privacy / legal: email `privacy@streampulse.stream`.
2. Security findings: GitHub Private Vulnerability Reporting
   ([`SECURITY.md`](SECURITY.md)).
3. Product bugs / features: use GitHub issues with the templates under
   `.github/ISSUE_TEMPLATE/` — no secrets, no exploit details, no raw chat.
4. Do not send credentials, DSNs, or production topology in email or tickets.
