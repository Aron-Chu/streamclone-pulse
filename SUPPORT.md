# Support

## Current verified contact

**`privacy@streampulse.stream`** — privacy and legal inquiries **only**. It is not a routine
product-support mailbox.

## Hosted support form

A hosted StreamPulse support form (Turnstile + durable outbox) is **planned** under RPR-4 and is **not active**.

Do not expect a working in-product support ticket path until activation is owner-approved and publicly disclosed.

## What not to use yet

The following are **not** published as active channels:

- `support@…` product-support mailbox
- `security@…` security mailbox
- GitHub Private Vulnerability Reporting (see [`SECURITY.md`](SECURITY.md))

## How to ask for help today

1. Privacy / legal: email `privacy@streampulse.stream`.
2. Product bugs / features (maintainers only while the repo is private): use GitHub issues with the templates under `.github/ISSUE_TEMPLATE/` — no secrets, no exploit details, no raw chat.
3. Do not send credentials, DSNs, or production topology in email or tickets.
