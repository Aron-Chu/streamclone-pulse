# StreamPulse brand mark — Peak

The canonical StreamPulse mark is a single chart-peak silhouette on a near-black rounded tile.

Runtime assets:

- Portal component: `streampulse-web/src/ui/components/BrandMark.tsx`

The mark appears in landing, analytics, and shared public navigation. Keep the SVG path aligned across the component and public assets. Extension store PNG artwork remains a separate CWS gate and must not be inferred from these portal assets.
